Review date: 2026-10-13

**The current implementation does not establish an independently valid habitat model or reliably bind its maps to their inputs.** The highest-priority failures concern inherited training leakage, same-shape checkpoint incompatibility, invalid-raster acceptance, temporal fallback, misleading ranking metrics, and destructive output publication.

This is a review of the supplied main-branch snapshot, not a PR diff: no comparison base was supplied. The review inspected the core acquisition, raster generation, analysis, split acceptance, dataset, training, checkpoint, calibration, and prediction modules, plus legacy execution guards. Historical bug records and the changelog were checked against code. Existing open findings are identified below; they are not presented as newly discovered regressions.

**Evidence limits:** no production rasters, trained checkpoints, CUDA runtime, PyTorch, or Rasterio were available locally. Small probes executed actual AST-extracted functions with NumPy/Pandas and controlled stubs, plus arithmetic reproductions. These establish the specified mechanisms, not their frequency in production. No model training, cloud export, production data repair, or repository modification was performed. Mitigation snippets are proposed changes, not applied patches. No Critical severity is assigned without evidence of an unconditional catastrophic failure; the unsafe deserialization finding is High because exploitation requires an untrusted resume artifact.

## Prioritized findings

### 1. High — Old checkpoints can import current validation labels into training

**Locations:** `model_handler.py:464–525,640–683,1092–1110`; `train.py:1074–1134,1284–1290`; `calibrate.py:86–133`. **Status:** confirmed structural gap; already tracked as BUG-0060.

**Failure scenario:** rebuilding a spatial split does not invalidate an old checkpoint. `--init-from`, `--resume`, distillation teachers, and calibration loaders accept weights based on architecture, without a digest or spatial footprint of the source training set. A teacher or initializer that previously trained on today's validation points transfers their labels into the new experiment. Standing checks validate today's CSVs, not the history embedded in weights. Thus a perfectly disjoint current split can still yield contaminated metrics. The repository explicitly records a split transition where old training negatives became new validation negatives; that historical count was not independently reproduced here.

**Mitigation:** save immutable training/validation point identities, split digest, accepted-input digest, git commit and dirty state with every checkpoint. At every load entry point require matching provenance, or prove the source training footprint does not intersect the target evaluation footprint. Record teacher and initializer ancestry recursively; a student needs its teachers' provenance as well as its own.

```python
def require_same_split(checkpoint, current_split_sha256):
    provenance = checkpoint.get("provenance")
    if not isinstance(provenance, dict):
        raise ValueError("Checkpoint has no verifiable split provenance")
    if provenance.get("split_sha256") != current_split_sha256:
        raise ValueError("Checkpoint was fitted under another split")
```

An SSL exception must be explicitly classified as transductive or inductive, rather than silently exempted from all evaluation-domain checks (see finding 5).

### 2. High — `load()` omits same-shape architecture checks

**Locations:** `model_handler.py:534–560,1976–1984`; `models.py:73–88,845–881`. **Status:** confirmed; configuration-check probe reproduced acceptance.

**Failure scenario:** `_model_config` compares only pooling, center skip, features, early resolution, early-attention presence and KV stride. It omits `early_attn_heads`, position mode, dual-branch settings and missing-mask semantics even though the checkpoint saves them. In attention with position mode `none` or `abs`, switching, for example, four to eight heads can retain the same Q/K/V and output parameter shapes. `load_state_dict` succeeds, but partitions the projections into different heads, changing predictions. `check_checkpoint_config` also skips any field absent from the stored config and all validation for a bare checkpoint. Successful tensor loading is not proof of behavioral compatibility.

`load_backbone` has a related boundary: it loads matching shapes before merely warning about feature differences. A changed continuous feature set with the same channel count can transfer a stem learned for another input meaning.

**Mitigation:** require a versioned, complete inference config; compare all behavior-changing fields before loading. Reconstruct deployment models from that config. For partial transfer, explicitly exclude input layers when feature identity/order/encoding differs, and exclude incompatible attention blocks.

```python
GEOMETRY_KEYS = (
    "features", "pool", "center_skip", "keep_early_resolution",
    "early_attn", "early_attn_heads", "early_attn_kv_stride",
    "early_attn_pos_mode", "dual_branch", "dual_branch_channels",
    "missing_mask", "vocab",
)
def check_config(saved, actual):
    if saved is None:
        raise ValueError("Explicit legacy migration required")
    absent = set(GEOMETRY_KEYS) - saved.keys()
    wrong = {k for k in GEOMETRY_KEYS
             if k in saved and saved[k] != actual[k]}
    if absent or wrong:
        raise ValueError(f"Missing config={absent}; incompatible={wrong}")
```

The schema should also include feature scales and storage-encoding versions; vocab sizes alone cannot detect changed input normalization.

### 3. High — Raster validity accepts missing data, while fallback bypasses the year gate

**Locations:** `grouse_data.py:308–410`; `train.py:287–326`; `dataset.py:131–135`. **Status:** confirmed; both validity cases and the filename-year check reproduced.

**Failure scenario:** `_is_valid_raster` marks any readable file with no declared nodata as valid, including a raster entirely filled with `-9999`. For NaN nodata, `data != src.nodata` is true even at NaNs, so an all-NaN raster reports 100% valid. The broad exception handler turns arbitrary read/programming errors into `False`, after which `raster_path` selects the latest valid year rather than the closest valid year.

The separate year-gap gate checks `raster_years`, which scans filenames. A 2020 row passes because `ME_2020_evt.tif` exists; if that file is corrupt, the reader can substitute 2025 despite tolerance 2. This silently introduces future landscapes and class-specific temporal substitution after the gate passed. Logging a warning does not enforce the temporal contract.

**Mitigation:** use finite, sentinel-aware masks, distinguish corrupt I/O from expected absence, and enforce year tolerance on the *resolved valid source*. Do not cache validity indefinitely without a file identity check.

```python
def valid_pixels(values, declared_nodata, sentinels):
    valid = np.isfinite(values) & ~np.isin(values, sentinels)
    if declared_nodata is not None and np.isfinite(declared_nodata):
        valid &= values != declared_nodata
    return valid

# After content validation has selected a real source:
if abs(source_year - record_year) > tolerance:
    raise ValueError("Resolved source violates year-gap policy")
```

Read validity in blocks to avoid the full-band memory allocation described in finding 17.

### 4. High — Average precision can reward a constant predictor with AP 1.0

**Locations:** `model_handler.py:78–90,630–635`; `train.py:405–412,452–461`. **Status:** confirmed executable reproduction.

**Failure scenario:** `average_precision` uses a stable descending sort and accumulates precision separately for every row, rather than grouping equal scores. Validation datasets concatenate positives before negatives for each region. With eight identical scores and labels `[1,1,1,1,0,0,0,0]`, the function returns **1.0**. Reversing label order returns **0.3654761904761905**. Correct threshold-based AP is **0.5** in both cases. Identical, quantized, saturated or collapsed scores can therefore produce inflated AP and affect `--select-by rank` checkpoint selection.

**Mitigation:** compute AP at distinct score thresholds, or use a well-tested implementation. Refuse non-finite scores and nonbinary labels before computing it.

```python
from sklearn.metrics import average_precision_score
def average_precision(scores, labels):
    scores, labels = np.asarray(scores, float), np.asarray(labels)
    if not np.isfinite(scores).all() or not np.isin(labels, [0, 1]).all():
        raise ValueError("Invalid ranking inputs")
    return float(average_precision_score(labels, scores))
```

Add a permutation-invariance test for tied scores and a constant-score baseline. The existing ROC-AUC tie loop is linear after sorting; it was not mistaken for an O(n²) loop.

### 5. High — Spatial split labels do not isolate feature footprints or model selection

**Locations:** `regions.py:45,239–253`; `dataset.py:314–342,425–436`; `pretrain.py:190–200`; `analyze_grouse.py:888–923`; `generate_negatives.py:240–260`; `model_handler.py:1272–1460`; `calibrate.py:229–239`. **Status:** design failure modes confirmed by call paths; several are already listed as D1–D4 follow-ups.

**Failure scenario:** assigning point centers to different 3 km blocks does not prevent 64×64 patches, approximately 1.92 km wide at 30 m, from sharing pixels across block edges. Jitter extends exposure. The runtime background sampler checks center block membership, not its full patch. SSL explicitly draws from validation blocks; this is transductive pretraining, despite its claim that absence of labels eliminates leakage.

Additionally, envelope binners and selection weights are derived from sightings before the split, so validation positives affect training-negative selection/weights. This occurs even without `--use-sample-weights`, because those weights influence the negative draw. Validation then drives checkpoint selection, dropout adjustment and divergence responses, and is reused for Platt fitting. Random calibration folds do not isolate spatial blocks or undo model selection. Reported validation accuracy/AUC/calibration therefore cannot be interpreted as performance on a geographically untouched external test set.

**Mitigation:** define the intended evaluation target explicitly. For an inductive habitat map, use train/validation/test *spatial polygons*, fit all supervised preprocessing on train only, and require each train/background/SSL patch footprint to lie inside train territory. Keep test labels out of all tuning, draw design and calibration.

```python
# footprint includes chip half-width, jitter and any preprocessing halo
safe_train = train_domain.buffer(-footprint_radius_m)
keep = safe_train.covers(point_geometry)
```

Use spatial group folds for calibration and reserve a final untouched test domain. A transductive experiment may be legitimate, but must be reported separately.

### 6. High — Resume artifacts permit arbitrary pickle execution

**Location:** `model_handler.py:1092–1093`. **Status:** confirmed unsafe load boundary; exploit conditional on an untrusted artifact.

**Failure scenario:** `torch.load(..., weights_only=False)` executes pickle reconstruction before any geometry check. An externally supplied or replaced `.resume` file can execute code with the training process's filesystem and credential access. The fact that optimizer state is needed does not itself establish that unrestricted pickle is necessary for this particular payload, which consists primarily of tensors and primitive containers.

**Mitigation:** try restricted loading for the actual resume schema, validate the result, and serialize unsupported state into a restricted representation rather than enabling arbitrary globals. Test optimizer, scheduler and scaler round trips under the project's pinned PyTorch version.

```python
state = torch.load(resume_from, map_location="cpu", weights_only=True)
if not isinstance(state, dict) or "model_state" not in state:
    raise ValueError("Invalid resume schema")
```

If unrestricted pickle remains necessary, accept only independently authenticated artifacts from a trusted producer. A checksum fetched alongside an attacker-controlled artifact does not authenticate it.

### 7. High — Calibration mismatch is warned about, then still applied

**Locations:** `calibrate.py:440–465`; `predict.py:928–983`. **Status:** confirmed call path.

**Failure scenario:** prediction reads and applies calibration before checking model identity. A different path, or a fit predating the checkpoint's mtime, produces a warning but keeps the scale and bias. Retraining in place, restoring timestamps, copying a checkpoint, or changing flip TTA can leave an unrelated calibrator attached. The saved `flip_tta` is not enforced, and no weight digest exists. These failures alter absolute scores and thresholds while preserving plausible map patterns.

There are also no strict finite/positive checks on manual temperature or loaded scale/bias/prevalence. Negative temperatures reverse rankings; zero or NaN parameters can produce broken outputs.

**Mitigation:** bind calibration to the weight digest and complete scoring contract, and refuse a mismatch. Validate values before applying anything.

```python
if cal["checkpoint_sha256"] != sha256_file(model_path):
    raise ValueError("Calibration belongs to different weights")
if cal["flip_tta"] != args.flip_tta:
    raise ValueError("Calibration scoring contract differs")
if not (math.isfinite(cal["scale"]) and cal["scale"] > 0
        and math.isfinite(cal["bias"])
        and 0 < cal["val_prevalence"] < 1):
    raise ValueError("Invalid calibration parameters")
```

Record source split, feature encodings, chip geometry and resolved raster vintages as well.

### 8. High — Missing-mask opt-out still manufactures physical zeros

**Locations:** `models.py:845–881,1107–1143`; `train.py:792–800,1263`; `grouse_data.py:220–249`; `train.py:1074–1134`. **Status:** confirmed; existing BUG-0059.

**Failure scenario:** `--no-missing-mask` and pre-mask checkpoints collapse categorical `MISSING_CODE` to embedding row 0 and continuous NaN to physical zero. The refusal guard depends on a coverage tag, rather than actual missingness, and is only called on selected prediction/calibration paths. Training can still use the opt-out, and the distillation loader does not apply this guard. A tagged repaired raster may be blocked for direct prediction but still produce a legacy teacher's poisoned soft labels. Untagged rasters with real nodata evade the guard entirely.

**Mitigation:** require missing-aware input semantics for new training and all teachers. For legacy compatibility, reject batches with missing or unknown values unless a separately reviewed legacy policy is selected; do not use a metadata tag as the validity decision.

```python
if not model.missing_mask:
    if (cat_x == MISSING_CODE).any() or not torch.isfinite(cont_x).all():
        raise ValueError("Legacy model cannot represent missing input")
```

Also reject unsupported negative categorical codes: the current masked embed path only flags `MISSING_CODE` and codes above vocab; other negative codes clamp to row 0 with validity marked true. Continuous validity must use `isfinite`, not just `isnan`.

### 10. High — Production outputs are truncated before replacement is known to succeed

**Locations:** `generate_time_since_disturbance.py:300–303`; `generate_treemap_features.py:310–316`; `model_handler.py:599–619,1355–1358,1970–1972`; `calibrate.py:463–465`; `predict.py:1098–1112`; `acceptance_split.py:229–242`; `prepare_training_data.py:211–225`. **Status:** confirmed publication mechanism.

**Failure scenario:** raster generators open live paths with mode `w` before processing all source blocks; an exception can leave a partial file while destroying its prior valid version. A partially filled raster may still pass the weak validity fraction and be consumed later. Checkpoint and resume writes similarly overwrite the last recoverable artifact directly. Prediction uses fixed `NH_custom_suitability.*` names, so different custom bounds/models overwrite one another, and concurrent runs can collide.

The split writer fsyncs the file but not the destination directory. Acceptance JSON/CSV writers rename unsynced staging files. Atomic visibility and crash durability are distinct properties.

**Mitigation:** stage privately on the destination filesystem, validate the completed artifact, fsync, replace, then fsync the directory. Use unique run directories and publish a manifest/pointer last for related files. Serialize publication or lock shared targets.

```python
def publish_bytes(path, payload):
    directory = os.path.dirname(os.path.abspath(path))
    fd, staged = tempfile.mkstemp(dir=directory, prefix=".stage-")
    try:
        with os.fdopen(fd, "wb") as out:
            out.write(payload)
            out.flush()
            os.fsync(out.fileno())
        os.replace(staged, path)
        dfd = os.open(directory, os.O_RDONLY | os.O_DIRECTORY)
        try:
            os.fsync(dfd)
        finally:
            os.close(dfd)
    finally:
        if os.path.exists(staged):
            os.unlink(staged)
```

For large GeoTIFFs/checkpoints, stream to the staged file instead of constructing a giant byte string. This Linux-oriented helper does not alone make a multi-file update transactional.

**Locations:** `acceptance_split.py:3133–3152,3155–3206`; `train.py:107–118`; `grouse_data.py:298–306,413–435`. **Status:** confirmed structural gap; conditional on inputs changing after acceptance.

Large-data hashing may be cached against a reliable immutable object version, but a filesystem mtime alone is not such a version.

### 15. Medium — Invalid calibration probabilities can report perfect reliability

**Location:** `calibrate.py:242–260`. **Status:** confirmed executable reproduction.

**Failure scenario:** `reliability` initializes ECE/MCE to zero and only increments bins matched by comparisons. NaN, Inf or out-of-range probabilities enter no bin. For `[NaN, NaN]`, it returns **ECE 0.0, MCE 0.0**, with every bin empty. A partially invalid vector also understates error because the denominator includes skipped values. ### 16. Medium — Cache coercion changes non-finite/float inputs before validity checks

**Locations:** `dataset.py:151–201,350–365,393–413`; `models.py:1122–1143`. **Status:** confirmed cast reproduction; conditional on out-of-contract input rasters.

**Failure scenario:** cache writes `np.nan_to_num(patch, nan=MISSING_CODE).astype(np.int16)` without checking finiteness, representable range or integrality. In the local NumPy probe, `1.75` became `1`, `40000` became `-25536`, and positive Inf became **0**. The live path also uses `nan_to_num` with its default Inf substitution, so cached and uncached inputs can diverge dramatically. A future float feature, malformed GeoTIFF, or changed storage encoding can silently fabricate values. Negative non-sentinel categorical codes are then treated as valid zero embeddings.

The cache key uses path/mtime and feature names, not a full storage/reader contract or content digest; equal-mtime replacement can serve stale data.

**Mitigation:** assert the documented integer storage contract before casting, map *all* non-finite values to missing, and reject overflow and fractional physical measurements. If floats are supported, keep float32 or use a declared reversible encoding.

```python
missing = ~np.isfinite(patch)
values = patch[~missing]
limits = np.iinfo(np.int16)
if (np.any(values != np.rint(values)) or
        np.any((values < limits.min) | (values > limits.max))):
    raise ValueError("Raster violates int16 cache storage contract")
stored = np.where(missing, MISSING_CODE, patch).astype(np.int16)
```

Validate fractional/null years before `dataset.py:102` casts them too. The CR-0031 helper validates its own years, but the dataset's general input boundary still truncates them.

### 17. Medium — Default worker/prefetch settings can exhaust RAM on large EC2 hosts

**Locations:** `train.py:104,557`; `model_handler.py:46–52`; `dataset.py:174–201,297–311`; `grouse_data.py:308–328`; `download_tcc_nlcd.py:410–428`; `download_treemap.py:306–336`. **Status:** confirmed allocation design; peak production use not measured.

**Failure scenario:** workers default to CPU count minus two, with four prefetched batches per worker. On a 128-vCPU machine that is 126 workers and up to 504 queued batches. At batch 256, four int64 categorical plus ten float32 continuous 64×64 channels already occupy about 72 MiB per batch: approximately **35 GiB** of prefetched tensors, before active batches, pinned copies, process/GDAL caches or raster buffers. Batch 512 doubles that. Every dataset leaf can retain handles to many resolved feature/year files per worker.

The validity probe reads entire bands, and the cloud download builders merge all tiles into full arrays plus dtype-conversion copies. Strip inference still materializes its full coordinate Cartesian product. These operations defeat streaming at the surrounding pipeline level.

**Mitigation:** choose worker/prefetch counts from an explicit host-memory budget and measured batch footprint, cap workers, stream raster validity and mosaic writes, and iterate coordinates lazily.

```python
batch_bytes = batch_size * pixels_per_chip * (
    8 * n_categorical + 4 * n_continuous)
workers = min(cpu_budget, max_workers,
              max(1, ram_budget_bytes // (prefetch_factor * batch_bytes)))
coords = ((y, x) for y in ys for x in xs)
```

Account for pinned duplication and active workers when selecting the budget; the formula is a lower-bound estimate, not a complete memory model.

### 20. Medium — Canadian land outside the template remains invisible to road-distance masking

**Location:** `generate_road_distance.py:224–291`. **Status:** confirmed code boundary; already tracked as a CR-0014 residual.

**Failure scenario:** roads are collected on a padded grid, but the Canadian-land mask and its distance transform are computed only on the unpadded template. If Canadian land is just outside that edge, a US cell may receive a known-looking distance to a distant TIGER road even though an unseen Canadian road could be closer. `land.any() == False` bypasses the uncertainty mask completely. Coverage of the output cell does not establish coverage of its nearest-neighbor search domain.

**Mitigation:** build source-coverage and Canadian-land masks over the same padded search domain as roads; mark distances unknown when nearer to any unobserved land/source boundary than to an observed road. Acquire cross-border road data to close the remaining domain uncertainty. Avoid an arbitrary finite padding silently acting as proof of complete nearest-road coverage.

### 21. Medium — The output affine disagrees with the scored center pixel

**Locations:** `predict.py:349–353,404–410,419–429`. **Status:** arithmetic reproduction; depends on the intended map-center convention.

**Failure scenario:** the code scores/captures the pixel at integer index `IMG_SIZE // 2`, whose physical center is at index `+0.5`. The output transform subtracts half an output pixel but omits that source-pixel `+0.5`. With 30 m pixels, chip size 64 and stride 4, the first reported output center is at source coordinate 960 m rather than the captured center pixel's 975 m: a 15 m discrepancy on each axis. If the intended location is instead the geometric center of an even-sized chip, document that different convention and reconcile it with point sampling and center-feature capture. The transform also does not correctly compose source rotation/shear terms.

**Mitigation:** define the output coordinate as the sampled center pixel and compose affines rather than reconstructing coefficients.

```python
center_col = c_start + IMG_SIZE // 2 + 0.5
center_row = r_start + IMG_SIZE // 2 + 0.5
new_transform = (
    ref.transform
    * Affine.translation(center_col - stride / 2,
                         center_row - stride / 2)
    * Affine.scale(stride, stride)
)
```

Test equality between output pixel centers and the chosen source center convention, including rotated-grid input.

### 22. Medium — Prediction's compile flag still compiles the unused entry point

**Locations:** `predict.py:314–316`; `models.py:803–840`; `model_handler.py:685–727`. **Status:** confirmed routing mismatch; GPU speed impact not measured.

**Failure scenario:** prediction wraps `model = torch.compile(model)`, which compiles `forward`. Its shared scorer calls `model.logits`, bypassing that compiled forward. Training correctly compiles `self.model.logits`; prediction retains the old pattern. The flag can print “Compiling model graph” while running the heavy scoring path eagerly, undermining throughput expectations for statewide mapping.

**Mitigation:** compile the callable actually used by `d4_tta_logits`, install or pass it explicitly, and verify compilation with profiler/compiler counters and equal outputs. Do not make compilation mutate unrelated global config by default.

## Additional boundaries requiring targeted follow-up

These are narrower conditional risks, not counted as separate prioritized vulnerabilities:

- **TreeMap source coverage:** `generate_treemap_features.py:307–322` uses an external NLCD footprint as coverage, while float sources with no nodata metadata can be padded by VRT with zeros. Its documented support for arbitrary region-specific source files requires a separate source-extent mask; a cropped source inside valid NLCD coverage can otherwise become nonforest outside its actual extent. Also normalize declared source nodata before `_clean`, and inspect the downloaded source masks rather than infer that every masked in-CONUS location is nonforest.
- **Background assignment schema:** `regions.block_split:270–286` accepts an empty assignment table (NaN validation fraction means all unassigned blocks become train), duplicates (last wins), or invalid split labels. Existing standing checks constrain the shipped training table, but the reusable helper should reject these inputs before sampling.
- **No-output SSL:** `pretrain.py:209–218,260–290` uses `drop_last=True` and saves an epoch even when the dataset is smaller than one batch. Require at least one optimizer step; a collapse warning is not proof that anything trained.
- **Edge diagnostics:** `predict.py:369–380` treats categorical missing-boundary transitions as ecological edges and converts continuous NaNs to zero before gradients. This is already tracked as BUG-0058. Use adjacent-pair validity masks and explicitly report unsupported edge values.
- **Provenance dirty state:** `acceptance_split.git_commit:170–182` ignores subprocess return codes and only recognizes selected tracked `.py` modifications. An unknown/failed status is not a clean tree. BUG-0068 remains relevant; store unknown distinctly and include relevant config changes/untracked source.
- **Source composition:** year matching fixed the direct year-label count imbalance, but the repository still records within-year acquisition/representative-year and wetland-guild differences. Equal counts are not evidence that these domain confounds disappeared; re-evaluate composition by year, region, source, species guild and resolved raster vintage on real data.

The immediate remediation order is checkpoint ancestry/config enforcement, raster validity and resolved-year checks, tie-correct ranking metrics, calibration binding, then staged output publication. A new spatial test domain is required before treating remaining validation scores as external habitat generalization evidence.
