Conclusions:
  1. EVT_PHYS spells the class "Agricultural" (47 EVT codes). The prefix "Agriculture" in
     analyze_grouse.py:127 never matches it (the strings diverge at the 11th character).
     "Agriculture" does occur in the table, but in the EVT_LF (lifeform) and EVT_NAME columns,
     which the filter does not read.
  2. "Barren" is not an EVT_PHYS value in LF2022/2023/2024; the barren class is
     "Quarries-Strip Mines-Gravel Pits-Well and Wind Pads" (EVT_LF Barren), already matched
     by the "Quarries" prefix. The "Barren" prefix is dead, not wrong.
  3. "Snow"/"Ice" match "Snow-Ice"; "Developed" matches all six Developed classes;
     "Open Water" matches. No false positives among the 19 real classes.
